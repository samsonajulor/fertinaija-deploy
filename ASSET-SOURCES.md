## Icons

The interface uses inline SVG paths from [Lucide](https://lucide.dev/) under the
[ISC licence](https://lucide.dev/license). The current set includes Hand Heart,
Circle Dot Dashed, DNA, Shield Check, Map Pin and Message Circle Heart.
